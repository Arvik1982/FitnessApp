# 💪 FitnessApp — Трекер тренировок (React Native + Charts)

## Что делает приложение
- Запись тренировок (упражнения + повторения + вес)
- Графики прогресса (линейные + бары)
- История тренировок по датам
- Offline-first (SQLite)
- Экспорт данных

[![FitnessApp Demo](https://img.shields.io/badge/Live_Demo-FF6B35?style=flat&logo=vercel&logoColor=white)](https://command-work-kurs-r2qs.vercel.app)


## Функционал
- ✅ Запись тренировок (упражнение/вес/повторы/сеты)
- ✅ Графики прогресса (линейные + бары)
- ✅ История по датам
- ✅ SQLite (оффлайн данные)
- ✅ Экспорт CSV
- ✅ Responsive (iOS/Android)
